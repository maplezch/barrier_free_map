# Proposal

## Why

当前项目只有问题陈述和访谈、问卷材料，缺少一个统一、易于公开访问的展示入口。需要建立一个托管在 GitHub Pages 上的中文静态网站，用于说明无障碍出行项目的背景、提案、团队与进展，并以结构化页面展示数据收集计划。

## What Changes

- 新增项目首页，展示项目背景与问题、项目提案、开发团队和项目进展。
- 新增独立的数据收集计划页面，展示访谈计划、访谈问题、问卷计划和问卷内容。
- 使用多页导航组织内容，便于后续增加文字材料。
- 支持团队成员姓名、头像图片和个人介绍的静态展示。
- 提供适合后续补充的项目进展时间线。
- 网站只展示静态文本和图片，不提供在线访谈或问卷提交功能。
- 不新增数据收集结果页面，也不在网站中展示调研结果。
- 采用中文、现代、清晰、朴素的视觉与交互风格。

## Capabilities

### New Capabilities

- `project-research-website`: 提供项目介绍、团队信息、项目进展和数据收集计划的中文静态多页网站。

### Modified Capabilities

无。项目当前没有已定义的可复用能力规格。

## Impact

- 新增 GitHub Pages 可托管的静态网页、样式、脚本和图片资源。
- 需要将现有问题陈述、访谈内容和问卷内容整理为网页文本。
- 不需要后端服务、数据库、表单接口或第三方数据收集依赖。
- 后续维护主要通过修改静态内容和资源完成。
